# SoulX 翻唱

正式翻唱链路为 **SoulX 演唱干声 → 当前上传的 RVC `.pth` 换声 → 混入伴奏**。语音回复继续使用原有的 CosyVoice3 合成再 RVC 换声。

## 使用

1. 在「设置 → 语音与翻唱环境」选择「歌曲 / 视频翻唱（SoulX + RVC）」并一键安装。已有 RVC 环境会先检查并复用；单独安装 SoulX 不会重装 TTS。
2. 在「能力 → 语音回复」选择或上传 `.pth` 和可选 `.index`。翻唱共用这个音色，不再单独上传模型。
3. 在「唱歌」启用聊天、选择歌曲来源。直接点歌，或发送/引用微信视频、抖音分享链接。页面试听仅生成本地音频。

## 音频来源

歌曲或视频先由 Demucs 分离人声和伴奏。原人声用于提取歌词、旋律和时间位置，SoulX 按这些信息重新演唱。SoulX 暂时使用官方示例参考声线；这个声线随后由所选 `.pth` 替换，只有经过 RVC 换声的结果才会进入最终混音。不会把原歌手干声混回去，也不会在换声失败后返回默认声线。

直接点歌、页面试听和视频参考演唱都先做「声学分析 → AI 自主编排」：结合可用画面、实际识别歌词、人格和分离音轨的测量，选择分句咬字、起句微调、句尾收放和力度曲线。SoulX 使用 score 模式重新生成旋律细节，再经 RVC 和力度处理混音。点歌的编排使用已配置的 DSH 模型；无法分析或编排时不回退为原唱换声。详见 [自主演唱编排](SINGING_PERFORMANCE.md)。这是单次演唱决策，不是对视频人物进行训练；哭腔、气声、嘶吼等没有独立控制参数。

伴奏来自当前歌曲/视频的分离结果，并非凭空生成。分离后仍可能有少量原唱残留；分离、歌词识别和上传模型质量都会影响成品。当前自动歌词与旋律预处理支持中文歌曲，不保证外语歌曲及纯伴奏输入可用。

每次最多 30 秒，CPU 生成通常需要数分钟，慢机器可能更久；运行超时上限为 45 分钟，可随助手关闭取消。建议至少 16 GB 内存、35 GB 可用磁盘。处理时会依次显示获取音源、分离、提取歌词旋律、SoulX 演唱、音色换声、伴奏混音。

## 安装、修复与来源

- 三套独立环境位于 `state/maintenance/audio-capabilities/feiyu-tts`、`feiyu-cover`、`soulx-singer`。RVC 由说话和唱歌共享，TTS 不参与唱歌。
- SoulX 预部署依赖包约 1.05 GB，由项目下载服务器提供；含可移植 Python 和 CPU 依赖，不含模型、私有音色、凭据或试听音源。
- 约 4.63 GB 的 SoulX 演唱与预处理模型从 Soul-AILab 官方 Hugging Face 仓库下载。源码、模型、分词资源均由随项目发布的固定清单校验，下载失败可复用本地缓存。
- 「检查环境」校验源码、依赖、全部模型及资源；安装/修复还会实际生成 5 秒 SoulX 干声验证，检查过程不发送微信消息。启用失败时自动回退，保留用户音色和配置。

具体固定版本见 `scripts/audio-runtime-manifest.json` 和 `scripts/soulx-assets.json`。生成目录中的 `soulx/result.json` 记录实际演唱，`rvc/cover_result.json` 记录实际模型摘要和换声调用，最终 `result.json` 记录链路、时长、音频摘要和混音来源。
