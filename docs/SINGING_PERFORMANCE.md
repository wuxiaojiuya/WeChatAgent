# 视频参考与自主演唱编排

这是所有唱歌请求的默认流程。直接点歌如「唱一段朋友的酒 DJ 版」，或在启用唱歌的聊天里发送/引用视频并说「你看看这个视频，学着这样唱给我听」。已成功解析的抖音分享同样适用。无需手动选择情绪或音乐参数，使用语音回复中选好的 RVC 音色，最多生成 30 秒。

## AI 实际做什么

1. 结合本轮视频采样画面、歌词转写及用户要求理解参考。
2. `wechat_analyze_singing` 取得当前聊天绑定的音轨，分离人声和伴奏，返回节拍估计、分句时间、音高范围、力度与起音密度等测量。
3. 对话模型结合测量、人格与用户意图判断情绪，为各分句安排咬字衔接、起句微调、句尾收放、音量及渐强/渐弱。方案以 `score-performance-v1` 结构提交。
4. SoulX 按谱面重新演唱。程序先改变音符和休止的时间分配，保持分句总时长，不把原演唱的逐帧 F0 传入生成。RVC 使用所选 `.pth` 统一音色，随后实际执行分句力度曲线，再与分离伴奏混音。

情绪是对话模型结合证据作出的演绎判断，声学测量不等于情绪分类器。当前能够执行的控制是谱面时值、休止、起句微调（最多 40 毫秒）、有可用休止时的句尾收放，以及分句轻重（±3 dB）和渐强/渐弱。模型自然生成更细的旋律表现，未提供气声、哭腔、嘶吼和指定转音的精确控制；不保证复刻参考人物唱腔。这也不是永久训练或学会一种唱法。

## 绑定和失败处理

参考音轨限当前聊天、视频与起点，30 分钟过期，一次生成后清理，不进入公共歌曲库。分析取消或聊天撤销授权时不提交生成；音轨校验、方案时段或实际执行校验不通过时返回失败。分析本身不发送微信。

生成目录保留 `performance.json`，`soulx/arranged-metadata.json` 记录实际修改后的谱面，`soulx/result.json` 记录 score 模式、时值修改数量及方案摘要，最终 `result.json` 还记录 RVC 模型摘要和力度执行。只有生成和执行校验通过才允许返回成品；微信投递仍以真实回执为准。

直接点歌和页面试听也必须先分析再编排：自动找歌 → 分离参考与伴奏 → 提取实际歌词、谱面与声学测量 → 通过已配置的 DSH 对话模型，结合当前人格与演绎意图作出分句决策 → SoulX score 重新演唱 → 所选 RVC 音色 → 分句力度 → 伴奏混音。页面试听用默认人格，只生成本机音频；需要 DSH 项目插件运行，不另填模型密钥。任务进度显示分析、AI 编排和演唱阶段。歌词识别可能有误，分析或模型编排失败时明确失败，不回退为原唱换声。已分析的分离结果与谱面校验后复用，不重复处理。

语音回复流程不变。原始伴奏保持速度和调性，自主编排受其节拍范围约束；原歌人声只作分析参考，不直接用于 RVC 输入。
