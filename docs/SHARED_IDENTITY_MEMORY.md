# DSH 共同记忆

DSH 在已允许的微信私聊和群聊中保持同一个持续交流的身份。不同会话分别保存原始对话，记忆可跨会话联想和检索；人格、表达与情绪由 AI 根据经历和当前场合判断，不设置固定情绪台词。

## 如何使用

在项目中启用聊天历史，并将需要参与交流的好友和群聊加入允许列表。无需为每个聊天重复建立一份共同记忆。每轮模型输入会自动参考其他允许聊天的近期经历和已有摘要；需要细节时，DSH 可以调用 `wechat_history_search` 搜索所有允许来源，或展开某条原消息附近的对话。

例如某位好友在群里说明周六有空，之后和 DSH 私聊时，DSH 可以检索那段群聊。但返回资料会注明群名、发言者、时间与来源会话，不把其他群友的安排安到这个好友身上。不同好友对 DSH 的昵称与私下约定也分别保留。

## 保存与范围

- 数据来自当前项目账号的聊天档案，包含已保存的聊天模式、助手模式记录及其摘要；重启后仍可检索。
- 只检索已允许且开启历史的微信会话。不导入无关 DSH 工作会话、内部推理或工具输出。
- 发送记录保留确认状态，AI 曾经生成的文字不自动等同于对方已收到。
- 每轮自动记忆最多 6,000 字符，包含有限近期记录和摘要；其他旧事通过检索读取。它不代表每轮把全部聊天原文重新发送给模型。
- 跨会话资料进入可替换的本轮上下文，不再作为新聊天记录归档，避免记忆反复复制。

关闭某个会话的历史或将其移出允许列表后，该会话退出后续共同记忆检索与上下文；关闭全局历史则停止共同记忆功能。原始档案继续按项目原有保存规则保留，开关不等同于删除。

这套功能不读取微信数据库。未被项目接收或保存的微信历史无法凭空恢复；旧摘要可能有遗漏，证据不足时 AI 应说明不确定。
