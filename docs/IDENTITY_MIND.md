# DSH 的共同状态与自主思考

在「记忆 → 自主思考」中，可以查看 DSH 保存的心情、简短想法、计划与执行记录，调整后台回顾和空闲行动设置。点击「保存设置」应用修改，无需重启微信。查看或刷新状态只读取项目自己的记录，不会调用模型或发送微信消息。

## 经历、关系与心情

允许范围内的群聊与私聊属于同一个 DSH 的经历。共同记忆保留原会话与真实发言者；关系、称呼和约定按稳定身份及会话来源保存，不会把某个好友给 DSH 的昵称当成所有人的叫法。心情是可延续、可调整的状态，不随聊天窗口切换重置，也不使用「遇到某个词就生气」的固定脚本。

页面展示的是状态摘要和可执行计划，不保存或展示模型的内部推理。已移出允许范围的聊天不再提供新的观察材料，查看状态也会过滤相应来源。

## 思考与行动分开

回顾不等于发言。DSH 可以记下「想找时间唱这首歌」，之后再执行、延后或放弃；也可以没有新想法，继续安静。后台回顾使用没有工具的模型调用，不能直接发送消息。

只有模型明确选定一个计划，且当前聊天范围和能力授权仍有效，才进入工具执行流程。唱歌和绘画默认作为本地练习保存；计划明确选择分享时，才发送至该计划绑定的聊天。朋友圈计划属于对外发布，不能因为它的 `delivery` 字段为 `local` 就视为私下保存。现阶段空闲朋友圈行动仅提供文字发布及回执查询。

「已提交，待结果」只表示生成任务或朋友圈接口接受请求，不表示生成完成、消息已发送或朋友圈已经发布。能力任务编号和简短结果保留在计划记录中，生成后的发送状态以能力任务及微信回执为准。行动中断或回执不确定时保留相应状态，不在重启后盲目重发。

## 默认设置

```json
{
  "wechat": {
    "identityMind": {
      "enabled": true,
      "idleEnabled": true,
      "idleMinutes": 20,
      "reflectionMinutes": 5,
      "dailyActionLimit": 4,
      "quietStart": "23:00",
      "quietEnd": "08:00"
    }
  }
}
```

- `enabled`：延续心情、关系、想法和计划的总开关。关闭会保留已有记录。
- `idleEnabled`：允许无人聊天时回顾。关闭后不因空闲唤醒；聊天之后仍可在总开关开启时整理状态。
- `idleMinutes`：开始空闲回顾前至少安静的分钟数，5–1440。
- `reflectionMinutes`：后台回顾的最短间隔，1–1440 分钟。选择沉默也可能产生模型用量。
- `dailyActionLimit`：每天最多进行的空闲对外行动次数，0–20。0 暂停对外行动，仍可安静回顾和进行本地唱歌、绘画练习。正常聊天和用户请求的唱歌、绘画不受此项限制。
- `quietStart` / `quietEnd`：北京时间的安静时段，不开始新的对外行动。起止相同表示不设安静时段，普通聊天照常回复；此前已提交的生成任务可能在之后完成。

有新聊天时优先处理聊天。停止助手或关闭 DSH 插件后，空闲回顾也会停止；重启不会补发旧行动。

状态保存在项目数据目录 `state/identity-mind/<连接范围>.json`。这是项目自己的状态文件，不读取微信客户端数据库。控制台的 `GET /api/identity-mind/status` 需要现有本机控制台令牌，只读且不触发行动。
