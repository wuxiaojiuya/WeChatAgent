# 语音情绪与接收媒体理解

## 语音回复情绪

能力目录 → 语音回复：情绪表达默认「AI 根据对话与人格自行判断」，可选始终平静；强度分为含蓄、自然、明显。AI 在 `wechat_voice_reply` 中为自己要说的话选择平静、开心、难过、不满、安慰、担忧或惊讶，不机械复制对方情绪。

本机肥鱼 CosyVoice3 使用 `inference_instruct2` 情绪指令，保留同一参考声线与正文；平静走原有 zero-shot。不使用变调代替情绪。效果受参考音频和模型影响，属于表达方式，不能保证每种情绪都像真人。配置窗口可选择情绪生成试听，不发送微信。

本机 CPU 冷启动与短句合成约需一分钟，试听总等待上限为 95 秒，超时或取消不会声称已发送。较长正文应拆成自然短句；首次生成可明显慢于后续识别。

`scripts/feiyu_emotion_overlay.py` 从固定 upstream release 构建项目自有适配目录 `state/media-runtime/feiyu-overlay`；不修改 upstream release。服务与工作进程均加载此适配层，并校验适配摘要。

## 接收语音

语音识别仍由可选 `speech-recognition` 插件管理，需要启用、授权 `audio_read` 并勾选聊天。本机已部署 Whisper small CPU int8，服务仅监听 `127.0.0.1:9881`，不向外部服务上传语音。

- 模型：`state/media-runtime/models/whisper-small`，独立 Python 环境位于 `state/media-runtime/venv`。
- 接口：标准文件转写，基础地址 `http://127.0.0.1:9881/v1`，模型 `whisper-small`。令牌保存于本机，不输出到日志。
- 单条 WAV 为 16kHz、单声道、PCM16，最长 60 秒；最多两条并发。识别受插件超时限制，较长录音在慢 CPU 上可能超时并保留失败提示。
- 对带伴奏的演唱，若语音活动检测未识别到文字且音轨有足够信号，会对完整的有限时长音轨再尝试一次；静音不重试，低置信度或异常重复的结果不会作为转写提供。歌曲歌词仍可能有识别误差。
- `scripts/manage.ps1` 检测到已安装模型后管理服务启动和停止；聊天期间不自动下载依赖或模型。
- `node scripts/setup-local-speech.mjs` 只授权执行时已经加入白名单的聊天，保留已有非本地服务配置。新增聊天需在插件设置里勾选。

## 引用附件

通过账号、聊天、完整服务器消息 ID、原发送者和消息类型回查原消息；不相信引用 XML 自报的附件路径。当前发言人的新回复和被引用历史保持分开。

图片/表情提供真实本机附件；语音按插件授权转写；视频走下述采样流程。引用文件支持普通文本、PDF 前 20 页及 DOCX，最多提取 6000 字。扫描 PDF 不做 OCR，压缩包、程序、旧 DOC 和表格二进制格式不执行、不猜内容。文件在独立进程中只读提取，读取前后复核身份、授权与摘要。

## 视频

支持微信普通视频消息（类型 43）及精确匹配的引用视频。先从已绑定原消息的 `cdnvideourl` / `aeskey` 通过供应 Hook 的 `/api/cdn_download`（`imgType: 4`）下载，与 XML 中的长度和 MD5 核对。该路径不依赖实时回调，重启后仍可读取具有有效 CDN 信息的历史视频。

CDN 不可用时，回退到 `/api/download_video`，需要原始 Hook 回调中的 `MsgId` 和完整 `NewMsgId`，两者不混用，不从数据库补查。缺少 CDN 信息与回调元数据的旧视频仍需重新发送。某些消息的普通下载接口会取得另一编码版本，却按 XML 中另一版本的长度提前结束；这种残缺文件不会送给 AI。每次在独立临时文件中下载，确认文件大小、稳定状态和 MD5 后才替换缓存；旧的残缺缓存可自动恢复。

单个源视频上限 100MB，最多处理前 60 秒、抽取 4 个静态画面，另将音轨转为语音识别输入。没有声音的视频仍可理解画面。图片输入按模型声明的 image modality 决定：当前模型支持则直接使用，否则仅尝试同一服务商明确声明支持图片的模型生成描述，不切换人格模型、不把聊天历史传给辅助模型。

无法获得原消息、下载信息、解码组件、授权或视觉模型时，保留新回复并明确说明缺失内容；不依据未提供的画面、声音或帧间动作猜测。
