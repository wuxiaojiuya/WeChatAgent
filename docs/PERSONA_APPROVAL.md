# AI 人格自主更新

新版人格生成和修改已不再需要审批。AI 可为当前会话形成自己的性格与说话习惯，更新后下一轮生效；也可以保持原样。详见[人格自主成长](PERSONA_EVOLUTION.md)。

「人格 → AI 人格成长」可查看更新内容、原因和自动回顾进度。管理员名单继续用于助手任务权限，与人格是否能成长分开。AI 可自行决定是否在对话里提及变化，不强制向管理员发私聊。

每次更新会保留原卡并创建当前会话的专属卡，备份位于 `state/persona-backups`。原卡、其他会话、账号和工具权限不受会话人格工具影响。应用时校验账号、聊天授权、卡片摘要、绑定和工作模式，避免覆盖手工修改。手工编辑、导入、删除和人格分组仍可使用。

旧版待审批申请保留为历史记录并停止审批；不会仅因升级就应用旧草案。`同意人格` / `拒绝人格` 旧指令只提示已切换为自主模式，不执行卡片修改。
