# 视频点唱

在已经启用「唱歌」的聊天中，发送视频，再说：

> 你看看这个视频，可以唱给我听吗？

也可以引用之前的视频提出相同要求，或直接粘贴抖音复制出的分享文字和链接。默认翻唱最多 30 秒；明确要求从某个时间开始时可选择开始秒数。

先发视频、随后单独提出点唱要求时，可使用当前聊天最近十分钟、最后二十条消息中的最近视频。群聊只关联同一发送者的视频；明确引用时优先使用引用，不用其他视频替代。较早的视频请直接引用。

## 处理流程

微信视频/抖音分享 → 账号和聊天绑定 → 最多四个画面采样及前 60 秒音轨转写 → AI 理解用户要求 → 取得精确视频片段并分离人声/伴奏 → 音轨声学分析 → AI 结合人格提交变调、分句力度与伴奏比例方案 → 原曲人声经配置的 .pth 模型换声 → 执行分句轻重和渐强渐弱 → 同步变调伴奏并混音 → 微信原生语音。

AI 先调用 `wechat_analyze_singing`，再调用 `wechat_sing_video` 提交方案；不能跳过分析或使用其他聊天的参考。参考音轨准备一次并复用，避免再次分离。具体支持范围见 [AI 编排翻唱](SINGING_PERFORMANCE.md)。直接点歌和页面试听也必须经过分析、AI 编排和原曲人声 RVC 换声，语音回复不变。

翻唱保留视频原唱的旋律、节奏、咬字与停顿，AI 安排整段升降调、分句轻重、渐强渐弱和伴奏比例；变调时伴奏同步处理。无需先猜出歌名再找替代音源。使用能力页已选择的 RVC 音色，不会自动训练或克隆视频人物声音。纯伴奏、说话视频、嘈杂原声或严重混响可能不适合演唱。

视频理解是采样，不是连续观看全部画面。歌词转写可能有误；没有取得画面、声音或微信回执时，AI 不应声称看过、听过或已经发出。

## 抖音链接

支持 v.douyin.com 分享短链、www.douyin.com/video/ 视频链接及官方 iesdouyin 分享链接。仅识别官方域名，不接收任意下载地址。

v0.2.0 安装包已内置固定版本的 yt-dlp 和 FFmpeg，支持抖音链接解析及视频音轨处理，无需另装 FFmpeg/ffprobe。源码部署需安装 `scripts/reader-requirements.txt` 中的读取器依赖；升级后需重启读取器和 Bridge/DSH 才能加载新代码。

抖音可能要求新 Cookie、登录或拒绝自动访问。可在本机「能力 → 唱歌 → 抖音访问 Cookie」填写网站访问 Cookie；密码框留空保留，支持单独清除。它仅存在本机 state 配置中，不回显至页面、不交给模型、不放进日志，只加入官方抖音域的 Cookie Jar。不要通过微信聊天发送 Cookie。

访问仍失败时直接发送视频文件即可，不绕过私密、登录、付费或其他访问控制。抖音源视频缓存按七天清理；翻唱临时 WAV 在任务结束后删除，不放入可跨聊天搜索的歌曲库。已有微信原始视频不属于音乐下载缓存，不删除用户的微信原文件。

## 验证范围

自动化覆盖：微信视频/引用绑定、抖音短链入口、跨聊天拒绝、撤销授权、格式与音轨摘要校验、视频原始双声道音轨、禁止联网、Cookie 隐藏/保留/清除，以及真实 FFmpeg 编码。使用合成视频和模拟的解析下载测试，不会自动给微信联系人发送消息。
