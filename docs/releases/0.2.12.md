# v0.2.12 · 精简音频环境与好友列表修复

本版将唱歌切换为「原曲人声 → AI 分析编排 → 所选 RVC 音色换声 → 混入伴奏」。直接点歌、歌曲试听、微信视频与抖音参考点唱使用同一流程；语音回复继续使用 TTS → RVC，共用所选音色。

## 翻唱与环境

- 分离人声与伴奏后，AI 根据音轨测量、可用画面与转写、用户要求和人格编排升降调、分句力度及伴奏比例；旋律、节奏和咬字沿用原唱。
- 设置页只保留 TTS / RVC 安装、检查与修复。唱歌只需 RVC/分离环境，最长 30 秒。
- 移除 SoulX 安装入口、预部署包引用、官方模型下载清单及推理脚本。升级自动清理应用管理的旧独立环境与旧脚本。
- 保留已上传 `.pth`、索引、音色档案、TTS/RVC 环境、已生成音频、歌曲来源凭证和历史任务。旧演唱任务可以查看，不会重新执行旧引擎。
- 实际耗时取决于歌曲下载、本机性能、分离和 AI 编排；减少一个生成阶段不代表所有机器都能实时翻唱。

## 好友与聊天名称

- 添加好友使用微信联系人库中的好友关系与删除状态筛选，排除群成员、陌生人、公众号、系统联系人及自身。
- 已添加聊天优先显示微信备注，其次昵称；无历史消息、尚未创建 DSH 会话也能显示。备注变更可刷新，离线名称按账号缓存。
- 保持既有聊天 ID、允许范围、管理员绑定及 DSH 会话历史。服务启动不自动重放旧消息。
- 清理已确认无用的 QQ 专用路由与文案，保留微信共用传输与桥接模块。

## 安装与升级

适配微信 **4.1.8.27**，需要独立安装 DSH 并启用项目能力插件。升级后重新打开 WeChatAgent，按页面提示加载新版 DSH 插件；已有 RVC 环境可复用。

基础安装包不包含大型音频模型；TTS、RVC 与分离模型从官方来源安装。升级只清理固定的旧引擎目录，不删除用户音色、歌曲与生成结果。

附件包括 Windows x64 安装包、源码 ZIP、Hook ZIP、SHA256SUMS.txt 与 VERIFICATION.json。打包验证不向微信联系人发送测试消息；校验范围和结果以 VERIFICATION.json 为准。
