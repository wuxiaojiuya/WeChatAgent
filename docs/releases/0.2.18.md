# v0.2.18 · 共同状态、自主思考与升级修复

## DSH 的共同状态与自主思考

- 允许范围内的群聊和私聊延续同一个 DSH 的经历，保留各人的关系、称呼和约定；心情状态跨会话保存，可根据交流调整。
- DSH 可以记下简短想法和计划，之后选择执行、延后或放弃。有新想法不等于立即发消息，也可以继续安静。
- 新增「记忆 → 自主思考」页面，查看状态摘要、计划与执行记录，设置空闲回顾、安静时段和每日对外行动次数。
- 空闲时可私下回顾，选择本地练歌、画图，或在现有能力与聊天授权范围内分享、发送文字朋友圈。有新聊天时优先处理聊天。
- 思考与工具执行分开：私下回顾本身不能调用工具，计划先保存再执行。页面仅展示状态摘要，不保存或展示模型内部推理；心情是可持续调整的状态，不代表真实主观情绪。
- 行动继续遵守聊天范围、能力授权、历史记录设置、安静时段和对外行动限额。本地练习不发送微信消息；已提交任务按真实结果结算，未知结果和重启中断的行动不盲目重试。

默认在空闲 20 分钟后提供回顾机会，后台回顾最短间隔 5 分钟；每日最多 4 次空闲对外行动，北京时间 23:00–08:00 不开始新的对外行动。回顾即使选择沉默也可能产生模型用量，可在页面关闭或调整。此前已提交的生成任务可能在安静时段内完成。

详细行为、状态说明和配置见 [共同状态与自主思考](https://github.com/wuxiaojiuya/WeChatAgent/blob/v0.2.18/docs/IDENTITY_MIND.md)。

## 配置保存与更新检查

- 修复添加聊天时，配置被后台或其他窗口更新后直接保存失败的问题。不同字段的改动会安全合并，好友、群聊和管理员名单按成员增删合并，再尝试一次保存。
- 同一字段出现不同改动、连接范围变化或再次发生冲突时，不覆盖已有配置，并保留当前草稿供继续处理；保存期间新增的输入也会保留。
- 修复已经安装最新版却仍提示更新的问题。检查器优先使用当前安装的发布身份，安装身份变化时失效旧缓存；确认已是最新版本后清除旧更新提示。
- 安装成功后同步工作区的版本快照，保留对同版本修订包的识别。

## 安装与升级

适配 **Windows x64、微信 4.1.8.27**，DSH 独立安装。

1. 保存正在编辑的设置，停止助手并退出旧版 WeChatAgent，运行新版安装包升级。
2. 升级保留配置、密钥、人格、音色、允许聊天和项目聊天记录。
3. 重新打开 WeChatAgent，按页面提示重新加载 DSH 桥接插件，再在概览启动助手，使共同状态和自主思考功能生效。
4. 在「记忆 → 自主思考」检查并调整空闲回顾与对外行动设置。

全部微信连接继续使用供应方 **4.1.8.27 Hook API 与 HTTP 回调**，不获取微信数据库句柄、不执行 SQL、不读取微信客户端数据库。共同状态保存在项目自己的数据目录中。
