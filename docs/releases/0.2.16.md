# v0.2.16 · 好友实时查询、私聊接收与绘画回复修复

## 添加聊天与私聊接收

- 每次打开“添加好友”即调用 Hook 的 `/api/update_all_friend`，等待本次完整好友响应；每次搜索或刷新都重新查询。
- 添加群聊直接调用 `/api/get_chatroom_list`。查询期间不显示上一次结果，失败明确报错，不回退旧目录。
- 移除每日后台同步和冷却限制，按完整查询所需时间调整页面与服务等待时间。
- 继续按真实好友关系过滤群成员、陌生人、公众号及系统联系人，不自动扩大允许聊天范围。
- 修复已允许私聊因联系人目录暂时缺失被丢弃的问题。接收和投递按稳定会话 ID 检查权限，保留去重与撤权复查，不补发旧消息。

## 绘画后的正常聊天

- 修复旧绘画任务的发送状态被带入后续对话，导致普通回复反复变为“图片已经生成，微信发送结果还没确认”的问题。
- 后续普通聊天恢复由 AI 正常回复；当前绘画任务的失败和未确认发送状态仍如实处理，不自动重发图片或伪造送达成功。

## 安装与升级

适配 **Windows x64、微信 4.1.8.27**，DSH 独立安装。

1. 停止助手并退出旧版 WeChatAgent，运行新版安装包升级。
2. 升级保留配置、密钥、人格、音色、允许聊天和项目聊天记录。
3. 重新打开 WeChatAgent，并按页面提示重新加载 DSH 桥接插件，使绘画回复修复生效；在概览启动助手。

全部微信连接仍通过供应方 Hook API 与 HTTP 回调，不获取微信数据库句柄、不执行 SQL、不读取微信客户端数据库。

## 验证与范围

发布前完成 Node 全量回归、独立 Python 接收与联系人测试，以及源码、Hook、安装资源和升级保留检查。具体测试数量与产物摘要见 `VERIFICATION.json` 和 `SHA256SUMS.txt`。

本机已验证添加好友能直接取得最新列表；未自动向真实好友发送测试消息，未在另一台物理电脑完成安装验收。绘画发送状态修复的自动化验证不代表第三方 Hook 已确认每张图片送达。

附件提供 Windows x64 安装包、源码 ZIP、Hook ZIP、`SHA256SUMS.txt` 和 `VERIFICATION.json`。
