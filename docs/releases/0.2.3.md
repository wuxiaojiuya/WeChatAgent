# WeChatAgent v0.2.3

修复 Windows 安装版点击“一键安装 TTS / RVC”立即出现 `AUDIO_DOWNLOAD_FAILED` 的问题。

- 桌面程序把内置 `node.exe` 路径传给音频安装器；修复原先误用 Electron 主程序 `WeChatAgent.exe` 启动下载脚本，导致下载立即退出的问题。
- 下载工具无法启动与网络下载失败分别提示；检查尚未安装的环境时明确提示先安装，不再出现找不到 Python 的原始异常。
- 增加控制台传递 Node 路径、独立 Python 调用真实 Node 下载工具、文件摘要校验的回归测试。
- 保留 v0.2.2 的微信连接修复、首次配置和此前语音、RVC 翻唱、视频与抖音点唱功能，适配微信 **4.1.8.27**。

## 升级后

从托盘完整退出旧版助手，安装 **WeChatAgent-Setup-0.2.3-x64.exe** 到原位置，保留本机数据。重新打开后，停止助手和单独运行的音频服务，再到“设置 → 语音与翻唱环境”点击一键安装。原先未完成的安装不会显示为已安装，下载缓存继续保留。

本次验证覆盖真实下载工具和摘要校验、独立目录首次部署检查及升级数据保留；未在另一台物理电脑完成安装验收。大型 CPU 环境和模型仍需联网下载，模型从官方来源获取，不包含在基础安装包中。抖音仍可能要求有效 Cookie。

附件包含安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json，不含个人配置、聊天、凭据或私人模型。
