# WeChatAgent v0.2.1

修复 v0.2.0 安装后的首次配置问题，继续适配微信 **4.1.8.27**，保留语音、翻唱、视频与抖音点唱及 TTS/RVC 一键安装、修复功能。

- **修复环境检查误报**：supplier-http Hook 不依赖旧方案的 `wx_key.dll`；改为检查内置 4.1.8.27 Hook 的 DLL、加载器及 SHA256。缺失或损坏的真实组件仍会报错。
- **补齐微信程序位置**：首次配置页可直接选择 `Weixin.exe` 并保存设置，再打开微信、登录和连接验证，无需先跳转连接设置。
- 检查 Node.js 时使用安装包内置路径，避免要求用户安装系统 Node.js。检查失败时显示具体组件错误，不再一律提示重装。
- 发布检查新增真实部署验收：在独立临时目录展开安装包资源、运行首次配置使用的完整检查脚本，并验证升级保留聊天设置、人格、自有模型与服务密钥。不启动微信或发送消息。

## 下载和升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.1-x64.exe**。从托盘完整退出旧版助手后安装到原位置，数据目录保留。首次配置选择匹配的微信程序后，先点击“保存设置”，再打开微信。

基础安装包包含 Node.js、读取 Python、Hook、yt-dlp 与 FFmpeg；DSH 和微信客户端独立安装，大型 TTS/RVC 环境与模型通过设置页另行下载。抖音访问可能需要有效 Cookie，平台拒绝访问时可直接发送视频文件。

附件包含安装包、源码、4.1.8.27 Hook、SHA256SUMS.txt 和 VERIFICATION.json。未在另一台物理电脑上完成安装验收，未对此前受 Cookie 限制的真实抖音链接完成下载与翻唱验收。
