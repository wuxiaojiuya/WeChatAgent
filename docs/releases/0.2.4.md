# WeChatAgent v0.2.4

改善 TTS/RVC 安装遇到官方资源拒绝访问时的诊断和恢复，继续适配微信 **4.1.8.27**。

- 官方资源返回 HTTP 403/429 时，显示站点和状态码，区分访问限制与普通网络错误，不再统一提示 `AUDIO_DOWNLOAD_FAILED`。
- 官方音色模型下载放入本机持久缓存，校验通过后复制到安装暂存目录。后续资源失败、环境回退和清理暂存目录时，保留模型下载与断点信息。
- 文本规范化等小型官方资源先于大型音色模型准备，避免大型下载完成后才发现资源不可访问。使用 ModelScope 官方公开文件下载入口，并继续强制校验已固定的 SHA256。
- 保留已有依赖包下载、已验证的默认模型与用户自有音色；缓存仅在本机保存，不将模型转存到项目下载服务器。
- 新增官方 HTTP 拒绝诊断、保留部分下载、模型缓存复用和损坏模型拒绝安装的测试。包含此前的桌面 Node 下载器、首次配置与微信连接修复。

本机已在安装版工作区完成 TTS/RVC 安装和后续环境检查：TTS 实际生成 2.84 秒中文语音，使用 WeText 文本规范化；RVC 完成 3 秒合成测试音的分离、换声和混音。这次安装复用了本机已校验的官方资源缓存，RVC 测试仅验证运行链路，不代表真实歌曲的试听质量。验证没有发送微信消息。

## 下载和升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.4-x64.exe**。从托盘完整退出旧版助手后安装到原位置，保留数据，再重开助手。音频安装/修复前停止助手及独立音频服务；成功安装不需要反复重装环境。

官方站点仍可能限流或拒绝访问。403/429 不代表模型损坏，应等待来源恢复；程序不会绕过登录或访问权限。已有缓存的安装验收不能证明其他网络环境下首次联网下载必然成功。

附件包含安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。大型模型和个人数据不随安装包分发。抖音链接可能需要有效 Cookie，此前受限的真实链接未完成翻唱验收。
