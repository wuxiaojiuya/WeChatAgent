# WeChatAgent v0.1.0

wuxiaojiuya 维护的首个定制发行版，适配 Windows 微信 **4.1.8.27**。

- 内置匹配 Hook，自动管理组件和本机接口。
- 好友/群聊人格对话、管理员与人格变更审批。
- 微信原生语音、AI 选择回复方式和情绪表达。
- 分离 + RVC + 混音翻唱，支持模型上传及 QQ/网易云/酷狗音源。
- 歌曲缓存七天清理，语音转写、引用附件与视频理解。
- 主页、反馈和更新源切换至 wuxiaojiuya/WeChatAgent。

附件提供 Windows x64 安装包、源码 ZIP、Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。

安装包包含 Node.js、Python 与 Hook，不含微信、DSH、音频推理环境、模型权重、歌曲或个人配置。新电脑仍需配置模型与聊天范围，音频能力需另行部署。详见 [首次使用](https://github.com/wuxiaojiuya/WeChatAgent/blob/main/docs/QUICK_START.md) 与 [音频环境](https://github.com/wuxiaojiuya/WeChatAgent/blob/main/docs/AUDIO_RUNTIME.md)。

此前已在开发机通过文件传输助手验证文字、短语音及约 30 秒带伴奏翻唱，用户确认手机正常播放。此版本不保证所有音乐音源和未来微信版本可用。
