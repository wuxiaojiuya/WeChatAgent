# WeChatAgent v0.2.5

统一语音回复与翻唱的音色管理，并支持上传参考录音直接合成语音。继续适配微信 **4.1.8.27**。

- 「语音回复」只选择音色，移除服务地址、手动 API Key 和高级服务选项。本机连接由项目管理。
- 在「语音回复 → 上传音色」集中新建或更新音色档案：上传参考录音和对应文字，用于 CosyVoice3 直接合成；同一处可上传配套 RVC 模型及索引，用于翻唱。
- 说话直接使用所选音色的参考录音合成，不经过 RVC 二次换声。保留 AI 自行决定语音回复、情绪与强度的设置。
- 翻唱自动沿用当前音色档案的配套模型，移除唱歌页面独立选模型和上传音色的入口。
- 保留原有 RVC 音色；只有 RVC 模型的旧音色会提示补充参考录音，不会悄悄改用默认声音。只有参考录音的音色可说话，翻唱需补齐同一音色的 RVC 模型。
- 包含 v0.2.4 的官方模型持久缓存、下载拒绝诊断，以及此前的音频安装、微信连接、视频与抖音点唱功能。

本机使用实际上传的 10.02 秒参考录音、RVC 模型和索引完成档案验证，直接生成 3.52 秒语音，推理回执确认 `runtime_rvc=false`。音色关联、旧配置迁移、原生语音发送与视频点唱相关自动化测试通过；这次验证未发送微信消息。音色相似度与歌曲效果需实际试听，上传者应确认参考录音与 RVC 模型来自同一音色。

## 下载和升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.5-x64.exe**。从托盘完整退出助手后安装到原位置，保留用户数据，再重开。已有可用的 TTS/RVC 环境和用户音色可继续使用，无需重复下载。

自定义说话音色需 3～30 秒清晰无伴奏录音和准确文字；RVC 的 `.pth` 文件不能直接合成文字语音。已有音色可在上传表单选择「更新」补充缺少的文件。

安装附件包含安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。用户录音、模型、密钥与聊天数据不随包分发。大型官方模型仍从原作者来源下载，首次安装依赖官方来源可访问；抖音链接可能需要有效 Cookie，受限的真实链接尚未完成完整翻唱验收。
