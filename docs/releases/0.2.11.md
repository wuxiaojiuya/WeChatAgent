# WeChatAgent v0.2.11

将唱歌、绘画和语音生成统一交给 DSH 能力插件执行，并修复「DSH 有多段回复，微信只收到第一句」的问题。继续精确适配 **微信 4.1.8.27**。

## 更新内容

- **职责整理**：WeChatAgent 负责能力设置、密钥、聊天授权、任务记录、环境管理和微信收发；DSH 能力插件执行唱歌、绘画和语音生成；DSH 中的 AI 理解意图、选择回复形式并编排工具步骤。
- **统一执行入口**：聊天工具与页面试画、语音试听、歌曲试听使用同一套 DSH 能力插件。歌曲搜索、下载与网易云登录验证也通过该插件执行。DSH 未就绪时明确提示，避免页面和聊天使用两套生成逻辑。
- **插件自动配置**：能力插件随现有桥接插件包一起提供和配置，无需手动注册第二个插件。修复绘画工具声明时机，按当前聊天授权提供可用能力。
- **保留原有流程**：说话继续使用 TTS → 所选 RVC 音色；唱歌继续使用理解参考 → AI 编排唱法 → SoulX 演唱 → 所选 RVC 音色 → 伴奏混音。现有音色、推理环境和配置目录保留。
- **微信多段回复修复**：兼容当前 Hook 返回的 `errCode: 1` 提交回执，避免把已经发出的第一句误判为未知结果而中断后续分条。后续消息仍需等待首条的微信数据库回执确认，通用成功响应不等于送达。
- **发送等待修复**：文字发送的外层等待覆盖 OneBot 的完整处理时间，减少回执稍慢造成的过早中断。继续保留未确认不自动重发、不中途补发历史剩余段落的保护。
- **生成任务保护**：能力请求绑定本机项目、账号和实例，保留取消、进度、结果校验与任务去重；未知生成结果不会自动重复调用收费接口。
- **升级状态核验**：检查实际加载的插件版本和能力协议，旧 DSH 进程不会再误报设置已生效；需要完整重开 DSH 时保留提示，加载新插件后可重新应用。
- **QQ 残留审查**：新增 [清理清单](../QQ_CLEANUP_REVIEW.md)，区分可移除的旧代码、需要先迁移的兼容分支和微信共用模块；本版未据此删除运行代码。

## 下载与升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.11-x64.exe**。

1. 从托盘完整退出 WeChatAgent 和 DSH，安装到原位置并保留用户数据。
2. 重新打开助手与 DSH，让 DSH 加载更新后的桥接和能力插件。已有旧版 DSH 进程需要在本次升级后完整重开一次。
3. 保持 DSH 打开，再使用聊天能力或页面试听。无需重新上传音色或重新安装已有且检查正常的音频环境。

现有人格、聊天设置、密钥、平台 Cookie、音色和音频环境保留。基础安装包仍不包含大型 TTS / RVC / SoulX 模型；需要时通过设置页从官方来源安装。

附件包含 Windows 安装包、源码 ZIP、4.1.8.27 Hook ZIP、`SHA256SUMS.txt` 与 `VERIFICATION.json`。私人配置、聊天、音频、图片、Cookie 和自有模型不随包发布。
