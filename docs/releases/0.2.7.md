# WeChatAgent v0.2.7

改善设置生效、语音工具调用和图片理解，继续适配 **微信 4.1.8.27**。

- **设置自动生效**：人格卡、昵称、唤醒词、聊天范围、回复节奏、管理员和能力开关保存后用于后续消息。模型设置通过本机接口等待当前任务结束后重载；连接设置改变时按需更新项目服务。失败时保留待应用状态和具体原因。
- **账号切换连接修复**：启动服务时自动同步模型连接与当前微信账号，保持不同账号的聊天和权限隔离。
- **语音/翻唱工具兼容**：支持新版 DSH 的原生工具声明，在模型可见范围和执行时均核验当前聊天权限。自动读取安装版控制台端口，修复页面运行中但语音工具连错端口的问题。
- **微信图片下载修复**：兼容实际消息中的 `length` 等长度字段；下载写入完成并通过解码与完整性校验后才提供给模型。下载失败不会用其他图片替代。
- **连续图片追问**：发送图片后再问“描述一下”“这张图里是什么”，会重新读取同一账号、聊天及发言人最近 10 分钟内的普通图片，避免上一轮已看图、下一轮却只有占位。仅在图片追问时重新带图；明确引用优先，读取失败时提供真实失败说明。
- **引用内容**：继续支持引用文字，以及定位原消息后读取引用图片、语音、视频和支持的文件。原消息和媒体仍需在当前账号可访问，图片理解取决于配置模型的视觉能力。

语音继续使用「TTS 合成 → 所选 RVC 模型换声」，翻唱保留已集成的分离、RVC 与混音流程。SoulX 本地演唱试听属于实验验证，尚未设为安装版默认翻唱流程。

## 下载和升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.7-x64.exe**。从托盘完整退出助手和 DSH，安装到原位置并保留用户数据，再重新打开；首次升级需要加载新版桥接插件，后续修改支持的设置无需手动重开 DSH。微信版本仍为 4.1.8.27，已有 TTS/RVC 环境和自有音色无需重复下载。

附件包含 Windows 安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。密钥、聊天记录、音乐、Cookie、自有模型和实验试听均不随包分发，大型模型仍从官方来源下载。

## 验证范围

自动化验证覆盖设置更新、账号隔离、新版工具声明、控制台端口发现、图片读取与追问、引用附件及安装资源。图片链路已在本机核对真实下载字节和首轮模型附件；修复后的追问通过隔离验证确认重新传入同一张图片。安装包执行独立首次环境检查和升级数据保留检查。

图片/语音/视频的理解质量取决于实际配置的模型；受限抖音链接仍可能需要有效 Cookie。本次发布不主动向微信联系人发送测试消息，也未在另一台实体电脑完成安装验收。
