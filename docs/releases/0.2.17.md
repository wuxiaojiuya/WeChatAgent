# v0.2.17 · 图片发送回执与绘画状态修复

## 图片接口成功状态

- 按供应方 `/api/send_image_msg` 文档处理 `{"code":1,"data":null,"msg":"success"}`，兼容当前 Hook 的 `errCode: 1` 成功响应。
- 收到明确成功响应后，图片任务记录为 `state:"api-acknowledged"`、`sent:true`、`confirmed:false`、`receipt:"supplier-api"`；绘画任务和 DSH 工具同步认可接口发送成功，不再等待文档未提供的微信消息号。
- 完整且目标匹配的原生服务器回执继续单独记录为服务器确认。接口成功不等于对方已读，不编造微信消息号、服务器回执或已读状态。
- 明确拒绝、冲突或无效响应不会记为发送成功。网络超时或结果未知时保留未确认状态，不自动重发。

## 重启与兼容

- 图片接口成功状态持久保存，重启后可恢复；重复查询或提交同一任务不会再次生成或发送。
- 升级前的旧未确认任务不自动追认成功，也不补发图片。
- 保留 v0.2.16 的好友实时查询、私聊接收授权和绘画后自然聊天修复，以及已有语音、翻唱与多模态功能；本次不改变语音、文件或表情的回执要求。

## 安装与升级

适配 **Windows x64、微信 4.1.8.27**，DSH 独立安装。

1. 停止助手并退出旧版 WeChatAgent，运行新版安装包升级。
2. 升级保留配置、密钥、人格、音色、允许聊天和项目聊天记录。
3. 重新打开 WeChatAgent，按页面提示重新加载 DSH 桥接插件，使图片状态修复生效，再在概览启动助手。

全部微信连接继续使用供应方 Hook API 与 HTTP 回调，不获取微信数据库句柄、不执行 SQL、不读取微信客户端数据库。

## 验证与范围

回归覆盖成功与失败响应归一化、图片任务持久恢复、去重、旧未知任务保护，以及绘画和 DSH 工具间的状态传递。各项发布检查结果、测试数量和产物摘要见附件 `VERIFICATION.json` 与 `SHA256SUMS.txt`。

本次没有向真实微信联系人发送图片测试，也未在另一台物理电脑完成安装验收；自动化回归不能代替接收端实际收图确认。

附件提供 Windows x64 安装包、源码 ZIP、Hook ZIP、`SHA256SUMS.txt` 和 `VERIFICATION.json`。
