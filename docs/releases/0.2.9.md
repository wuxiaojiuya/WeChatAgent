# WeChatAgent v0.2.9

新增网易云账号凭证配置，让点歌取源使用自己的登录账号；改善翻唱失败时的对话回复。继续精确适配 **微信 4.1.8.27**。

## 更新内容

- **网易云登录凭证**：在「能力 → 唱歌」选择「网易云音乐」，歌曲来源下方自动显示 Cookie 输入区、获取说明和「保存并验证网易云登录」。切换其他来源时隐藏该区域，保留已有凭证。
- **使用账号获取音源**：搜索和音源解析使用当前保存的凭证，账号验证请求网易云官方接口。凭证仅保存在本机，不回显至页面、不交给 AI、不携带到其他音乐平台或音频 CDN；输入框留空保留，支持单独清除。
- **如实解释翻唱失败**：当模型已自然说明真实失败原因或发送未确认状态时，微信保留符合人格的说明与建议；继续阻止虚构生成进度、完成或送达。平台未返回音源时说明实际结果，不擅自归因为付费、登录或版权。
- **演唱流程保持一致**：直接点歌、页面试听、微信视频和抖音参考演唱继续使用「理解参考 → AI 编排 → SoulX 演唱 → 所选 RVC 音色 → 伴奏混音」。语音回复继续使用 TTS → RVC。

## 下载与升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.9-x64.exe**。从托盘完整退出助手和 DSH，安装到原位置并保留用户数据，再重新打开，让 DSH 加载新版桥接插件。现有人格、设置、音色和已安装的音频环境保留。

升级后打开「能力 → 唱歌」，选择「网易云音乐」，按「如何获取登录凭证」说明填写网页版 Cookie，再点击「保存并验证网易云登录」。请在本机页面填写，不要通过聊天发送。会员歌曲能否取得音源、是否只能试听，仍以账号权限和网易云的实际返回为准。

附件包含安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。密钥、Cookie、聊天、歌曲、自有音色与模型不随包分发，大型音频环境和官方模型仍通过设置页安装。

## 验证范围

自动化测试覆盖凭证保存、保留、清除、输入校验、页面条件显示、账号验证、搜索与取源携带凭证、禁止跨平台和 CDN 携带凭证，以及翻唱回复与会话恢复。发布包另外核验源码和资源摘要、内置运行时、隔离首次部署和升级数据保留。
