# WeChatAgent v0.2.2

修复安装包点击“连接并验证”时出现 `HOOK_PROBE_FAILED` 的问题，继续适配微信 **4.1.8.27**。

- 连接检查脚本显式添加同目录模块路径，兼容安装包独立 Python 的 `_pth` 隔离模式，修复找不到 `supplier_api` 的启动错误。
- 依赖缺失、Python 路径失效、检查超时及接口未启动分别提示具体原因；异常结果只包含安全的代码、类型和模块名，不输出原始异常内容或凭据。
- 首次环境检查和发布验收会在全新子进程中启动连接脚本，验证模块加载，不要求登录微信或联网。
- 包含 v0.2.1 的首次配置微信程序选择、环境检查修复，以及此前语音、翻唱、视频/抖音点唱与 TTS/RVC 安装、修复功能。

## 下载和升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.2-x64.exe**。从托盘完整退出旧版助手后安装到原位置，保留数据。选择匹配的 `Weixin.exe` 并保存，从项目打开微信、登录后点击“连接并验证”。

本次已在本机实际安装目录完成 4.1.8.27 Hook 身份、登录账号、联系人及消息数据库核验并绑定账号，没有向联系人发送测试消息。另有独立目录首次部署、环境检查和升级数据保留验收，未在另一台物理电脑上验收。

安装包包含读取 Python、Node.js、Hook 和媒体工具；微信与 DSH 独立安装，大型音频环境和模型在设置页另行下载。抖音链接仍受平台访问限制，可能需要有效 Cookie；此前受限链接未完成真实翻唱验收。

附件提供安装包、源码 ZIP、Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json，不包含个人账号、聊天、配置或密钥。
