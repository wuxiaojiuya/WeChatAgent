# WeChatAgent v0.2.10

新增 GPT 绘画与 AI 人格自主成长，修复唱歌任务恢复和消息回执处理。继续精确适配 **微信 4.1.8.27**。

## 更新内容

- **GPT 绘画**：在「能力 → GPT 绘画」配置支持 GPT Image 的服务地址、API Key、模型、尺寸、画质与允许的聊天。可在页面本地试画；对话中明确要求画图时，AI 在当前允许的聊天中生成并提交图片发送。本地试画不发送微信。
- **生成任务与发送状态**：任务持久保存并支持继续查询，同一次请求不会自动重复调用付费接口。生成完成与微信确认送达分别展示；超时或结果不确定时不冒认成功、不自动重发。图片经过格式校验，API Key 仅保存在本机并脱敏显示。
- **AI 自主生成默认人格**：人格页新增重新生成入口，使用当前已配置的对话模型生成，应用前备份旧卡。手动编辑与版本冲突不会被静默覆盖。
- **人格自主成长**：每 20 次有效互动回顾，每个会话 24 小时最多一次；有稳定依据时直接更新专属人格，不再请求管理员审批。保留旧卡备份，各会话独立成长；AI 可自行决定是否在当前对话说明改动。升级保留现有人格，默认不会自动替换用户原卡。
- **唱歌与回执修复**：完善生成任务中断后的恢复与查询，修复旧任务、旧回执误匹配，减少重复生成与不确定发送状态造成的阻塞；SoulX → RVC → 伴奏混音与语音 TTS → RVC 流程保持一致。

## 下载与升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.10-x64.exe**。从托盘完整退出助手和 DSH，安装到原位置并保留用户数据，再重新打开，让 DSH 加载新版桥接插件。现有人格、聊天设置、密钥、音色与已安装的音频环境保留。

绘画默认关闭，需在「能力 → GPT 绘画」填写自己的可用 API Key 并启用允许的聊天。使用前可先检查模型，再进行本地试画；模型检查成功不代表已完成真实出图验证。人格页可选择「AI 重新生成默认人格」，后续聊天按自主成长规则调整。

附件包含安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。个人密钥、Cookie、聊天、生成图片、歌曲和自有模型不随包分发；大型音频环境与官方模型仍从设置页安装。

## 验证范围

自动化检查覆盖绘画配置与密钥脱敏、请求去重、任务恢复、图片校验、聊天范围、原生图片发送合同及不确定投递处理，以及人格生成、冲突保护、备份与自主回顾。发布验收另核对源码和资源摘要、内置运行时、隔离首次部署及升级数据保留。

本机已验证绘画能力页面加载与 AI 生成默认人格生效；本次尚未配置真实绘画 API Key，未调用付费出图接口或发送真实测试图片。Hook 若改写图片，无法精确匹配回执时会保持未确认状态。尚未在另一台实体电脑完成安装验收。
