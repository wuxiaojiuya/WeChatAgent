# WeChatAgent v0.2.6

修复 RVC 音色无法保存和生成说话试听的问题，将说话流程调整为「TTS 合成语音 → 所选 RVC 音色换声」。继续适配微信 **4.1.8.27**。

- 语音回复与翻唱共用一个 RVC 音色。在「语音回复 → 上传音色」上传 `.pth` 模型和可选 `.index` 索引即可，无需参考录音或录音文字，已有 RVC 音色可直接沿用。
- 「保存并检测音色」核验 TTS 服务、所选模型和 RVC 环境；「保存并生成试听」先合成，再换声。错误原因直接显示在对应按钮下方。
- 保留 AI 自行选择文字或语音、判断情绪和表达强度的设置；基础语音的情绪表达再经过所选模型换声，效果以实际试听为准。
- 换声结果核验源音频、模型与输出摘要；失败时明确报错，不返回基础音色冒充所选音色。延长生成等待时间，兼容本机模型加载与两阶段处理。
- 包含此前的音频环境一键安装与修复、歌曲来源、微信视频和抖音链接点唱、微信原生语音及多模态理解功能。

## 验证

本机已用现有 RVC 音色完成两阶段真实推理，生成约 2.3 秒试听；安装版页面的保存检查通过，点击生成按钮后得到约 2.5 秒试听和播放器，回执确认 `runtime_rvc=true`。本次测试未发送微信消息。相关自动化测试覆盖音色上传、旧配置迁移、两阶段合成、失败处理、原生发送、视频点唱与安装器。

## 下载和升级

Windows 10/11 x64 下载 **WeChatAgent-Setup-0.2.6-x64.exe**。从托盘完整退出助手，安装到原位置并保留用户数据，再重新打开。已有可用的 TTS/RVC 环境和音色模型无需重复下载。

说话试听需要 **TTS 和 RVC 两套环境均就绪**，并启动本机语音服务。只有参考录音、没有 RVC 模型的旧音色，需要在同一上传入口补充模型。

附件包含 Windows 安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 和 VERIFICATION.json。用户音色、密钥及聊天数据不随包分发，大型模型仍从官方来源下载。首次模型下载取决于官方来源可访问；受限抖音链接可能需要有效 Cookie，真实受限链接的完整翻唱尚未验收。
