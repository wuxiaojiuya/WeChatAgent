# WeChatAgent v0.2.0

新增设置页一键安装与修复本地语音和翻唱环境，并将此前的语音服务自动连接、视频点唱与抖音链接点唱纳入 Windows 安装包。继续适配微信 **4.1.8.27**。

## 本次更新

- **一键安装 TTS / RVC**：进入「设置 → 语音与翻唱环境」，可选择全部、仅 TTS 或仅 RVC；显示下载进度和检查结果。
- **一键修复与检查**：重建独立推理环境、修复路径和缺失资源；保留服务密钥、自有音色与聊天设置，新环境验证失败时恢复旧环境。
- 依赖包从项目下载源获取并校验 SHA256，支持断点续传；默认音色从作者官方来源下载到项目数据目录。
- 本机肥鱼服务自动读取访问凭据，默认无需用户填写 API Key；自定义服务保留高级配置。
- 微信视频、引用视频和抖音分享链接可用于点唱，使用原视频音轨经分离、RVC 换声和混音生成最长 30 秒片段。
- 补充 AI 安装指南，修复中文目录的文本规范化、Windows 长路径及环境迁移问题。

## 下载与升级

Windows 10/11 x64 用户下载 **WeChatAgent-Setup-0.2.0-x64.exe**。升级前在概览停止服务，并从托盘完整退出旧版助手；安装到原位置以保留数据。首次使用音频能力，到设置页安装环境，再到能力菜单配置语音回复和唱歌。

安装包包含桌面应用、Node.js、微信读取 Python、链接解析依赖与匹配 Hook。微信客户端和 DSH 仍需独立安装。大型音频推理环境和模型通过设置页另行下载，不随基础安装包分发。环境安装目前支持 Windows x64 CPU，需至少预留 20 GB 空间，并能够访问官方模型下载源。

## 验证与附件

安装/修复、音频能力、设置导航、升级及更新检查通过自动化测试。独立目录已验证短句 TTS、3 秒合成音调的分离/换声/混音、修复损坏配置，以及保留服务密钥和自有音色。合成音调测试用于验证处理链路，实际翻唱效果需要用歌曲试听；首次模型全量下载受官方来源可达性影响。

本次发布核对打包资源、版本与 SHA256，并检查干净部署和升级保留。未向微信联系人发送测试消息，未在另一台物理电脑进行完整安装验收。

附件包含 Windows x64 安装包、源码 ZIP、4.1.8.27 Hook ZIP、SHA256SUMS.txt 与 VERIFICATION.json。个人配置、聊天记录、密钥、歌曲和私人模型均不包含在发布附件中。
