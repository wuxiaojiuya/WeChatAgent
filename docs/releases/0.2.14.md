# v0.2.14 · 共同记忆与微信推送接口

DSH 在群聊和私聊中共用持续的交流身份与记忆；微信接收改为 Hook 推送、项目缓存和专用 API，当前 supplier-http 路径不读取或修改微信数据库。

## 共同记忆

- 当前项目账号所有已允许且开启历史的微信会话共享经历，包括普通私聊、群聊、助手模式群友聊天与已有助手模式记录。
- 每轮自动参考有限近期经历和摘要，需要细节时由 DSH 搜索共同档案；保留原会话、发言者、时间、称呼关系和发送确认状态。
- 记忆持久保存，重启后可检索；临时记忆上下文不重复写成新聊天。关闭历史或移出允许范围后，相关来源退出后续共享上下文与检索。
- AI 根据共同经历与当前场合延续想法、情绪和表达；不同好友的昵称与约定分别保留，不设固定情绪台词。

## 微信接口与自主工具

- 接收改为 Hook HTTP 推送和项目自己的有界持久缓存；不获取数据库句柄、不执行 SQL，不回退到微信数据库读取。运行时不重复查询或比较登录账号。
- 接入好友列表、群列表、群成员、语音下载、MP3 原生语音、原生 @、引用回复和拍一拍，保留既有 SILK 语音及翻唱通道。
- 向 DSH 提供文字朋友圈、图片朋友圈、朋友圈回复、自己昵称、头像、签名、当前群名七类自主动作，以及朋友圈查询和操作状态工具。
- API 已受理与服务器已确认分别记录；未知、超时和中断不自动重发。修复重复回调的媒体关联、中文路径和本地表情任务处理。

## 升级与使用

适配 **微信 4.1.8.27**，继续使用独立 DSH。升级前停止助手并退出旧程序；安装后准备配置并重新加载新版 DSH 插件。已有设置、密钥、人格、音色和项目聊天档案继续保留。

共同记忆需要开启聊天历史，只覆盖项目保存的允许会话；未接收的微信旧消息不补查数据库。引用附件与原生引用发送需要同会话原消息已缓存。只获得 API 受理时不冒充最终送达。

供应方文档明确提示文字朋友圈接口可能导致微信断线；图片朋友圈目前一次支持一张图。部分朋友圈查询、评论及资料修改接口缺少响应结构，未知结构会报错，未公开的评论编号不会猜测。其他限制见 [Hook 接入说明](../SUPPLIER_HOOK_41827.md)。

## 验证与附件

共同记忆与原生会话回归 98 项通过，覆盖群聊、私聊、助手群友入口、来源撤销与历史开关。专用 API、持久回调、媒体和工具映射另有离线验证；打包检查验证首次部署、升级保留、内置运行环境和文件摘要。具体构建结果以附件 `VERIFICATION.json` 为准。

本次发布验证不重启真实微信、不发送测试消息或朋友圈，也未在另一台物理电脑完成安装验收。移除数据库访问不表示已证明之前微信失去收发的唯一原因。

附件提供 Windows x64 安装包、源码 ZIP、Hook ZIP、`SHA256SUMS.txt` 与 `VERIFICATION.json`。
