# GPT 绘画

在项目「能力 → 能力目录 → 绘画与素材 → GPT 绘画」中配置服务、检查连接和生成本地试画。配置保存后对后续聊天生效。

## 接入绘画服务

填写 API 基础地址、API Key 和服务商提供的 GPT Image 模型名称。OpenAI 基础地址为 `https://api.openai.com/v1`；兼容服务需提供 `POST /images/generations`，支持 `model`、`prompt`、`n: 1`、`size`、`quality`、`output_format: "png"`，并返回 `data[0].b64_json` 中的 PNG 图片。不读取服务商返回的外部图片 URL。

模型是否可用取决于服务商的实际授权。选择尺寸和画质后，点击「保存并检查连接」。检查通过只表示凭据与模型访问正常，实际绘画仍需通过试画验证；部分兼容服务不支持模型查询，可直接试画。试画会调用绘画 API，按服务商规则计费。

API Key 仅保存在本机的绘画配置中，不随源码、安装包或聊天提示发送；调用你配置的绘画服务时用于鉴权。留空保留已保存的 Key；更换基础地址时重新填写对应服务的 Key。

## 本地试画与聊天绘画

「保存并生成试画」只在项目窗口预览，**不发送微信**。生成中关闭配置窗口不会取消后台任务；重新打开同一项目页面中的配置窗口，会恢复查询。进度读取失败时使用「继续查询上次试画」，不要另外提交一张。已确认失败或已完成后，可以再次生成新试画。

启用绘画开关并勾选允许的好友或群聊后，在微信中明确提出绘画要求，例如「帮我画一只窗边看雨的小猫，水彩风格」。AI 整理描述后生成图片，并向当前聊天发送微信图片。仅让 AI 看图、识别或描述内容，不会被当成画图请求；需求不清楚时先说明想画什么。

## 结果与发送状态

任务启动、图片生成和微信送达是三个不同阶段。生成完成后仍可能遇到微信连接或权限变化；发送未确认时只核对回执，不自动重发图片或重新生成。可以追问「刚才的画生成了吗」，由 AI 查询当前聊天的任务状态。

出现鉴权、模型不存在、额度或参数问题时，按页面提示修正配置。请求超时可能意味着结果未知，程序保留请求编号避免自动重复生成。项目或服务重启后不会擅自重跑中断的付费请求。
