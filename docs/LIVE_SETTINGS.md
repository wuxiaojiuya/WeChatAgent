# 设置自动生效

人格卡、昵称与唤醒词、聊天范围、回复节奏、历史窗口、管理员以及能力开关保存后供后续消息使用，无需重新打开应用。正在生成的回复保留其已接收的输入和发送回执。

模型设置通过受认证的本机接口重载 DSH 桥接运行时。它等待正在执行的任务完成，释放旧事件监听和会话句柄，再按当前模型和账号恢复会话；聊天记录与不同账号的隔离保持不变。切换微信账号后，启动服务时自动重载模型连接。

程序位置、端口或媒体连接改变时，项目会自动准备配置，必要时重新连接由项目管理的后台服务。原本停止的助手保持停止。应用失败会保留设置和待应用状态，页面提供“重新应用”和具体错误；不会将失败显示为已生效。

首次从不支持热重载的旧插件升级时，需要完整重开一次 DSH 来加载新版插件。后续修改设置无需手动退出 DSH。首次配置、DSH 登录及安装插件仍需先完成。

兼容较新的 DSH：提示词文本组装接口可能不再包含工具列表，工具声明由每个 Agent 的 executor 提供。本项目在声明生成前按当前聊天授权过滤，在执行时再次校验权限，保留 DSH 原生审批。旧版接口继续使用原有组装过滤。

语音、翻唱与人格提案工具按项目运行记录发现控制台当前端口，每次操作重新读取，支持安装版自动分配端口及重开后变更端口。连接仍限定本机回环地址，并在提交操作前核对项目目录和控制台身份，不需要用户配置 HTTP 地址。
