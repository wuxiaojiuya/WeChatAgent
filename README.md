# WeChatAgent

**让微信 AI 朋友拥有自己的性格、声音与歌声。**

由 [wuxiaojiuya](https://github.com/wuxiaojiuya) 维护的 Windows 微信 AI 助手定制版。

[下载安装](https://github.com/wuxiaojiuya/WeChatAgent/releases) · [首次使用](docs/QUICK_START.md) · [提交问题](https://github.com/wuxiaojiuya/WeChatAgent/issues) · [更新记录](RELEASE_NOTES.md)

## 当前源码架构

| 层次 | 职责 |
| --- | --- |
| WeChatAgent | 能力设置与密钥、任务记录、聊天授权、微信消息接收与发送，以及本机音频环境的安装、检查和修复 |
| DSH 能力插件 | 调用绘画与语音服务，执行歌曲搜索与下载、原曲音轨分析、AI 编排执行、RVC 换声和伴奏混音 |
| DSH 中的 AI | 理解用户意图，决定回复文字、发送语音、绘画或唱歌，并编排工具调用与演唱方式 |

能力插件随现有桥接插件包自动配置和加载，无需再手动注册一个插件。生成图片、语音或歌曲，以及在线歌曲搜索与登录验证时，DSH 必须打开并加载当前项目插件；插件未就绪时明确提示失败，WeChatAgent 不回退到控制台进程执行生成。

设置、密钥、音色和推理环境仍保存在当前项目的数据工作区，无需因职责调整搬迁目录。页面试画、语音试听和歌曲试听同样通过 DSH 能力插件执行，只在本机展示结果。以下描述对应当前源码，已发布安装包的内容以对应 Release 为准。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自然聊天 | 好友/群聊白名单、唤醒词、人格卡、上下文、成员记忆与主动消息 |
| 共同记忆 | 同一账号允许且开启历史的群聊、私聊共享 DSH 的交流经历；保留来源、发言者、称呼关系与发送状态，重启后仍可检索 |
| 微信专用接口 | 仅使用微信 4.1.8.27 内置 Hook；推送接收消息，好友、群、成员与媒体使用专用 API，不读取微信客户端数据库 |
| 微信自主管理 | DSH 可调用原生 @、引用、拍一拍、MP3 语音及朋友圈、昵称、头像、签名、当前群名工具；操作按真实回执记录 |
| 人格自主成长 | AI 可生成默认人格，后续每 20 次有效互动回顾（每会话 24 小时最多一次），有依据时自主调整并备份；无需审批，可自行决定是否说明改动 |
| 原生语音 | TTS 合成后使用所选 RVC 音色换声，发送微信语音条；AI 自行选择回复方式、情绪和表达强度 |
| 对话点歌 | 直接说「你会唱朋友的酒 DJ 版吗」，AI 选择歌曲、版本并发起翻唱 |
| AI 编排翻唱 | 原曲人声 → AI 分析编排 → 上传的 `.pth` 换声 → 伴奏混音；可控制变调、分句力度和伴奏比例，旋律、节奏与咬字沿用原唱 |
| 歌曲来源 | QQ 音乐、网易云、酷狗或本地音源；网易云支持本机登录凭证配置与验证，下载缓存默认七天清理 |
| 视频点唱 | 发微信视频或抖音分享链接，说「学着这样唱给我听」；结合画面、歌词与音轨分析编排，最长 30 秒 |
| 消息理解 | 语音转写、图片、引用内容与附件、视频抽帧和音轨转写 |
| GPT 绘画 | 能力菜单配置 GPT Image 服务、尺寸、画质与聊天范围；本地试画不发微信，对话中明确要求画图时生成并发送图片 |
| 设置自动生效 | 人格、聊天和能力设置供后续消息使用；模型与连接按需自动重载 |
| 能力与插件 | WeChatAgent 页面统一配置，DSH 插件执行能力，DSH 中的 AI 选择并编排工具；保留插件 API、记事本和扩展入口 |
| 音频环境管理 | 设置页一键安装、检查或修复 TTS / RVC 环境（分离依赖包含在 RVC 环境中）；音色从官方来源下载到本机项目目录 |

## 运行要求

- Windows x64，当前发布版精确适配 **微信 4.1.8.27**。
- 独立安装的 DSH Desktop，以及可用的对话模型。
- 语音、唱歌、ASR 需要相应服务、推理环境和模型；基础安装包不包含大型音频模型资源。
- 图片和视频需要支持图像输入的模型，实际理解能力取决于所配置的模型。

Hook 随 Windows 安装包提供，无需填写 DLL 路径或自定义 HTTP 接口地址。不要混用不同微信版本的组件。

## 快速开始

1. 从 Releases 下载 Windows 安装包。
2. 在连接设置选择匹配微信与 DSH，点击“打开微信”自动加载内置 Hook；登录后到概览点击“启动助手”，程序自动准备连接。
3. 在 DSH 配置模型，安装并启用项目桥接插件包；能力插件随包自动加载。添加允许的聊天并选择人格。
4. 使用语音或唱歌时，先到 WeChatAgent「设置 → 语音与翻唱环境」一键安装，再到「能力」配置和启用。保持 DSH 打开，先生成本地试听验证。

详细步骤及源码运行见 [安装与首次使用](docs/QUICK_START.md)，音频依赖见 [音频运行环境](docs/AUDIO_RUNTIME.md)。

## 发布与隐私

当前正式版 **v0.2.14**。本版新增群聊与私聊共同记忆，微信接收改为 Hook 推送与项目缓存，并补齐原生消息及自主管理工具，详见 [版本说明](docs/releases/0.2.14.md)。主页、下载和更新源均为本仓库。应用检查正式 Release；仅推送代码不会触发版本更新。私有仓库的附件需要有权限的 GitHub 账号登录下载，匿名更新检查无法读取私有 Release。

配置、API Key、聊天记录、歌曲和私人模型保存在本机，不随源码或安装包分发。反馈问题时请移除账号、聊天内容及凭据。
